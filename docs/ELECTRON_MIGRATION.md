# Electron 桌面迁移

选型：Electron + React + TypeScript + Vite。Python 保留知识点匹配、AI 出题与审核、题库构建、SQLite 学习数据和 Windows 凭据管理。选择 Electron 的依据是固定 Chromium 渲染环境、成熟的多窗口支持和桌面集成，接受额外的程序体积及运行内存。

## 视觉方向

面向开发者日常学习，页面采用左侧固定导航、右侧内容工作区。练习列表与独立答题窗口各有明确职责。内容左对齐，解析阅读宽度受限，长代码块独立横向滚动，操作栏固定在阅读区外。

颜色：背景 `#F4F6FA`、正文 `#202938`、次要文字 `#586579`、主色 `#4338CA`、成功 `#176448`、错误 `#B42332`。中文使用本机 Microsoft YaHei UI / PingFang SC，英文沿用系统 UI 字体，代码使用 Cascadia Code / Consolas。标题 26px，正文 15–16px，阅读正文行高 1.8，间距使用 4/8px 网格。

设计检索两次分别返回营销页和儿童教育方案，未采用；上述方向是依据实际桌面学习场景制定的人工设计判断。遵守键盘操作、可见焦点、文字对比、减少动态效果和控件显式标签的通用指导。

## 运行结构

React → 受限 preload 接口 → Electron 主进程 → JSON 行协议（stdin/stdout）→ Python 应用任务层 → 现有引擎。

渲染进程开启 sandbox / contextIsolation，禁用 Node 集成；不直接读数据库、系统凭据或文件。Python 的 stdout 专用于协议，日志单独输出并脱敏。新题列表不包含答案，判分成功后才返回解析。窗口之间共享练习状态，关闭答题窗口只隐藏，提交任务继续完成。

现有 Tk 入口及发布流程暂保留作兼容回退，Electron 有独立构建命令。对既有安装流程的替换必须以 Electron 打包和安装生命周期实测为依据，不能沿用 Tk 时代的验收结论。
